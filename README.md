# Лабораторная работа №1: Алгоритмизация

## Вариант 18: Площадь круга и кольца

Консольное приложение на C#, предназначенное для вычисления площадей круга и кольцевой области.

### 📋 Описание

Программа предоставляет пользователю меню с тремя задачами:
1. **Площадь большого круга** — вычисление по формуле `S = π × R²`
2. **Площадь малого круга** — вычисление по формуле `S = π × r²`
3. **Площадь кольца** — вычисление площади кольца и его доли от площади большого круга по формуле `S_кольца = π × (R² - r²)`

### ⚙️ Технические требования

- Радиусы `R` и `r` должны находиться в диапазоне **0.01 – 1000**
- Для задачи №3 необходимо предварительно ввести значения `R` и `r` в задачах 1 и 2
- Значение `r` должно быть строго меньше `R`
- Дробная часть чисел вводится **через запятую** (например: `3,14`)
